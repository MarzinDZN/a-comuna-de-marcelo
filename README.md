# 🔴 A Comuna de Marcelo

> *"The philosophers have only interpreted the world, in various ways. The point, however, is to change it."* — Karl Marx

A personal blog with a communist editorial slant. A space for critical thinking, class analysis, and ideas that don't fit anywhere else.

---

## 🛠️ Tech

Built with vanilla **HTML**, **CSS** and **JavaScript** — no frameworks, no backend, no database.

Posts are managed through a single `posts.json` file. To publish, just add a new entry to the array.

```json
{
  "id": "003",
  "data": "2026-05-01",
  "manchete": "Article title here",
  "resumo": "Short summary.",
  "corpo": "Full article body..."
}
```
